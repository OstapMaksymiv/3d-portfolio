Roomzy

Roomzy is a passion project built to simplify finding, booking, and managing accommodations. Using React and GSAP, I crafted a smooth, beautifully animated frontend that offers personalized recommendations and real-time availability checks. On the backend, Node.js, MongoDB, and WebSockets work together to ensure all booking data remains perfectly synchronized.

Skills: React, Node.js, MongoDB, WebSockets, GSAP, Zustand, UI/UX Design, Prisma

Gastroly

As my culmination project at UITM, I built Gastroly—a full-stack B2B marketplace designed to streamline connections between suppliers and buyers in the HoReCa sector. Using React Native and Node.js, I engineered a powerful search dashboard with geolocation filtering and architected a real-time chat via Socket.IO. It's a robust, highly interactive platform built for seamless enterprise use.

Skills: React Native, Node.js, PostgreSQL, Socket.IO, Geolocation, Real-time Chat, REST APIs
